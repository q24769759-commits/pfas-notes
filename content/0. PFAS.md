# PFAS 介紹

---
## 1. 什麼是 PFAS？

目前多數國家 PFAS 管制皆參考 [^1]OECD（2021）PFAS 定義。

![[Pasted image 20260625144236.png]]

# OECD 如何定義 PFAS？

> **具有至少一個全氟甲基（–CF₃）或全氟亞甲基（–CF₂–）結構的有機含氟化合物，即屬於 PFAS。**



PFAS 不是單一化學品，而是一大類含氟有機化合物，目前已知超過 **10,000 種**。
PFAS 的共同特色是含有非常穩定的 **碳-氟鍵（C-F bond）**：

- 含有碳（C）與氟（F）形成的 **C-F 鍵**
- C-F 鍵是有機化學中很強的化學鍵之一
- 極難被自然環境分解
- 因此容易在環境中長期殘留

## 2. PFAS 為什麼用在紡織？

PFAS 過去在紡織業被大量使用，主要是因為它能讓布料表面產生排斥水、油、污的效果，特別適合戶外、軍用、醫療與工作防護類產品。

### 紡織加工上的主要功能

| 功能 | 說明 |
|---|---|
| 防潑水 | 常見於 DWR 防潑水整理，讓水滴不容易滲入布面 |
| 防油 | 降低油污滲入纖維或塗層表面的機會 |
| 防污 | 使表面較不容易沾附髒污，提升清潔性 |
| 防指紋 | 用於部分表面處理或特殊塗層 |
| 防沾黏 | 用於需要降低表面黏附的材料或加工 |
| 耐化學品 | 用於特殊工業、醫療或防護用途 |

### 常見紡織加工

- 防潑水加工（DWR）
- 防油加工
- 防污加工
- 防指紋加工
- 防沾黏加工
- 特殊塗層或表面整理

### 常見紡織產品

| 產品 | 使用原因 |
|---|---|
| Outdoor Jacket | 需要防潑水、防污與耐候性 |
| Rain Coat | 需要防水或防潑水效果 |
| Military Fabric | 可能需要防水、防油、防污與耐化學品 |
| Medical Textile | 可能需要防污、阻隔或特殊表面性能 |
| Workwear | 可能需要防油、防污或防護性能 |

過去很多紡織防潑水與防油整理會使用 **C8** 或 **C6 Fluorocarbon** 系統。

### 其他非紡織用途

PFAS 也曾被用於食品包裝、滅火泡沫、半導體、電子材料、不沾鍋塗層與醫療材料等領域。但在這份筆記中，重點以 **紡織、染整與黏扣帶相關來源** 為主。

### 受到限制的原因

PFAS 同時也具有環境與健康疑慮：

- 不易分解
- 可累積於人體
- 可累積於環境
- 部分 PFAS 已證實具有毒性

因此各國法規與品牌標準開始逐步限制 PFAS。

## 3. PFAS 的化學結構

PFAS 的核心特徵是：

```text
Carbon (C) - Fluorine (F)
```

也就是穩定的：

```text
C-F
```

常見含氟結構包含：

```text
CF3
CF2
CF2CF3
CF2CF2CF3
```

其中 **CF2** 與 **CF3** 是 PFAS 中常見的含氟片段。

### 全氟（Perfluoro）

全氟表示碳鏈上的氫幾乎全部被氟取代。

範例：

```text
CF3-CF2-CF2-
```

### 多氟（Polyfluoro）

多氟表示只有部分氫被氟取代。

範例：

```text
CHF2
CH2CF3
```

## 4. PFAS 分類

| 類型 | 說明 |
|---|---|
| Perfluoroalkyl | 全氟烷基 |
| Polyfluoroalkyl | 多氟烷基 |
| Fluoropolymer | 氟聚合物 |
| Side-chain Fluorinated Polymer | 側鏈氟化聚合物 |

## 5. 常見 PFAS

| 名稱 | 常見說明或用途 |
|---|---|
| PFOA | 防潑水、防油相關應用 |
| PFOS | 防污、防油相關應用 |
| PFHxA | 新一代短鏈 PFAS |
| PFNA | 表面活性劑相關 |
| PFBS | PFOS 替代品 |
| GenX | PFOA 替代品 |
| FTOH | 氟調聚醇 |

## 6. 黏扣帶與染整製程的可能來源

若產品沒有特別做防潑水，通常本體材料本身不一定需要使用 PFAS。

常見本體材料：

- Nylon
- Polyester
- PU

但 PFAS 或總氟仍可能來自製程或外部材料。

### 可能來源

| 來源 | 說明 |
|---|---|
| 防潑水整理 | 最需要優先確認 |
| 防油整理 | 可能使用含氟整理劑 |
| 離型紙 | 可能帶入含氟表面處理 |
| 離型膜 | 可能帶入含氟材料 |
| 表面塗層 | PU、塗層或特殊表面處理需確認 |
| 部分助劑 | 柔軟劑、整理劑、加工助劑等 |
| 外購化學品 | 需向供應商索取聲明或檢測資料 |

所以有時會出現：

> 原料明明沒有 PFAS，但成品檢測卻出現總氟。

---

## 7. 對人體與環境的影響

目前研究認為，部分 PFAS 可能與以下風險有關：

- 肝功能影響
- 免疫系統下降
- 生殖毒性
- 發育毒性
- 荷爾蒙干擾
- 某些癌症風險增加

不同 PFAS 的毒性不同，不能把所有 PFAS 視為完全相同的風險，但整體法規趨勢正在朝更嚴格管理發展。

---

## 8. 法規與品牌要求趨勢

目前常見關注來源包含：

- 歐盟 REACH
- POPs Regulation
- 美國 EPA
- 美國多州 PFAS 法規
- OEKO-TEX
- ZDHC
- bluesign

### 主要趨勢

| 過去 | 現在與未來 |
|---|---|
| 限制少數特定 PFAS，例如 PFOA、PFOS | 逐步轉向限制整個 PFAS 類別 |
| 只看目標物清單 | 更重視總氟、未知含氟物與供應鏈來源 |
| 單點檢測 | 供應鏈聲明、助劑管理、製程排查一起做 |

---

## 9. 重點整理

| 項目 | 重點 |
|---|---|
| PFAS 是什麼 | 一大類含有高度氟化碳結構的有機化合物 |
| 為何好用 | 防水、防油、防污、耐熱、耐化學品 |
| 為何受管制 | 難分解、可累積，部分物質有健康與環境風險 |
| 紡織業來源 | 防潑水整理、防油整理、含氟助劑、塗層、離型材料 |
| 黏扣帶排查重點 | 原料、助劑、PU 樹脂、加工、包裝與外購材料 |
