# 1. PFAS 介紹

## 1-1. 什麼是 PFAS？

目前多數國家 PFAS 管制皆參考 [^1]OECD（2021）PFAS 定義。

![[Pasted image 20260625162058.png]]

### OECD 如何定義 PFAS？

> **具有至少一個全氟甲基（–CF₃）或全氟亞甲基（–CF₂–）結構的有機含氟化合物，即屬於 PFAS。**

PFAS 不是單一化學品，而是一大類含氟有機化合物，目前已知超過 **10,000 種**。
PFAS 的共同特色是含有非常穩定的 **碳-氟鍵（C-F bond）**：

- 含有碳（C）與氟（F）形成的 **C-F 鍵**
- C-F 鍵是有機化學中很強的化學鍵之一
- 極難被自然環境分解
- 因此容易在環境中長期殘留

---

### PFAS 的化學結構

PFAS 的核心特徵是：

```text
C-F
```

其中 **CF2** 與 **CF3** 是 PFAS 中常見的含氟片段。

#### 全氟（Perfluoro）

碳鏈上的所有氫原子皆被氟原子取代。

![[Pasted image 20260625153829.png|296]]

#### 多氟（Polyfluoro）

碳鏈上僅部分氫原子被氟原子取代，仍保留部分 C–H 鍵。

![[Pasted image 20260625154003.png|298]]

## 1-2. PFAS 受到限制的原因

- **難以分解（Persistent）**
    - C–F 鍵為自然界最強的共價鍵之一。
    - 在環境中可存在數十年至更久，因此又被稱為 **Forever Chemicals（永久性化學物質）**。
- **可能累積於人體與生物（Bioaccumulative）**
    - 部分 PFAS（如長鏈 PFAS）可累積於人體血液及野生動物體內。
    - 長期暴露可能提高健康風險。
- **部分 PFAS 具有毒性（Toxicity）**
    - 部分研究指出，某些 PFAS 可能影響：
        - 肝臟
        - 免疫系統
        - 生殖與發育
        - 血脂及膽固醇
    - 並非所有 PFAS 都具有相同毒性。

因此各國法規與品牌標準開始逐步限制 PFAS。

## 1-3. PFAS 在紡織業用途

PFAS 過去在紡織業被大量使用，主要是因為它能讓布料表面產生排斥水、油、污的效果，特別適合戶外、軍用、醫療與工作防護類產品。

### 紡織加工上的主要功能

| 功能 | 說明 |
|---|---|
| 防潑水 | 常見於 DWR 防潑水整理，讓水滴不容易滲入布面 |
| 防油 | 降低油污滲入纖維或塗層表面的機會 |
| 防污 | 使表面較不容易沾附髒污，提升清潔性 |
| 防指紋 | 用於部分表面處理或特殊塗層 |
| 防沾黏 | 用於需要降低表面黏附的材料或加工 |
| 耐化學品 | 用於特殊工業、醫療或防護用途 |

### 其他非紡織用途

PFAS 也曾被用於食品包裝、滅火泡沫、半導體、電子材料、不沾鍋塗層與醫療材料等領域。

### 可能來源

即使原料未直接添加 PFAS，PFAS 或總氟仍可能來自製程或外部材料。

| 來源 | 說明 |
|---|---|
| 防潑水整理 | 最需要優先確認 |
| 防油整理 | 可能使用含氟整理劑 |
| 離型紙 | 可能帶入含氟表面處理 |
| 離型膜 | 可能帶入含氟材料 |
| 表面塗層 | PU、塗層或特殊表面處理需確認 |
| 部分染助劑 | 柔軟劑、整理劑、加工助劑等 |
| 外購化學品 | 需向供應商索取聲明或檢測資料 |

所以有時會出現：

> 原料明明沒有 PFAS，但成品檢測卻出現總氟。

[^1]: OECD（經濟合作暨發展組織）為國際政府間組織，發布多項化學品管理與測試指引，供各國制定政策及法規參考。
